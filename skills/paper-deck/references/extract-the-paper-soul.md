# 论文的魂 → Paper Brief

deck 做得好不好,全在这一步。动 HTML 之前,先产出一份 **Paper Brief** 并和用户确认过。

PDF 直接用 Claude 的 Read 工具读——它原生支持读文字和图,不要为此另外引入 PDF 解析栈(不装 pdfplumber/PyMuPDF 之类)。

## 阅读顺序(信号从高到低)

1. **摘要 + 引言。** 问题是什么、缺口在哪、贡献声称是什么——这是论文自己给自己的框定,权威来源。先读这里。
2. **方法 / 途径章节。** 核心 idea 和机制怎么 work 的——这一段将成为 deck 的**交互**部分,读的时候就要留意"这三步能不能演出来"。
3. **结果 / 实验。** 分清哪些是真被展示的(有表、有图、有消融),哪些只是被声称的(正文一句话带过、无图表支撑)。
4. **相关工作。** 读者(尤其是同行)已经默认接受的基线是什么,这篇论文新在哪——没有这一节,"贡献"就悬空。
5. **局限 / 有效性威胁 / 结论。** 论文自己承认的诚实边界,通常是最容易被略过、但对可信度最重要的一节。
6. **图与图注。** 往往是通往方法与结果最快的路径——一张图 + 图注常常比三段正文讲得更清楚,读不懂正文时先看图。

若用户点名某一节("看 Section 4""看这张图"),先读它,让它给整个叙事定锚。

## The Paper Brief(每个字段都要有证据,标注来自哪节 / 哪图 / 哪表)

```
RESEARCH QUESTION (1 句):这篇论文要回答的问题,用论文自己的话。
GAP:现有做法在哪失败——张力所在(相关工作/引言里的"however…""despite…")。
CORE IDEA / CONTRIBUTION (1 句能复述):听众只记住一句时,是这句。
METHOD IN 3 STEPS:机制怎么 work 的三步——交互的候选(→ 见 paper-narrative 的 show-then-name)。
KEY RESULTS:支撑主张的 1–3 个数字/图——这些是要"抽原图"的结果图(→ extract-pdf-figures.sh)。
AUDIENCE:讲给谁(领域内同行 / 跨领域 / 领导)——定语域。
VOCABULARY:论文自己的 5–12 个核心术语,逐字照抄 + 一句白话注解。这是全 deck 唯一可用词表。
HONESTY(分级,带证据):论文声称 / 已复现 / 存疑 各列条目 + 依据。
```

每个字段都要喂给一个具体产物:RESEARCH QUESTION → 封面与开场;METHOD IN 3 STEPS → 第一个交互;KEY RESULTS → 结果图(要抽原图);VOCABULARY → 每页的词表白名单;HONESTY → 现状/局限页。喂不到任何东西的字段就别加。

## 说论文自己的语言(不可谈判)

deck 必须用**论文自己的词**来讲它的概念——不生造术语,不换一个自己觉得更顺口的近义词,不用论文没提过的词。自造或"听起来很聪明"的词汇,是让懂行听众出戏、让外行听众更困惑的最快方式。

- **从论文实际命名的地方挖真术语**:方法名、模块/组件名、指标名、数据集名、章节标题、公式里的符号名。优先取在论文里出现最一致、作者反复使用的那个说法。
- **逐字照抄。** 论文写"attention head",就别写"注意力单元";论文写"ablation",就别升级成"敏感性分析"。casing、拼写、中英混用,照论文原样(包括论文本身中英夹杂的写法)。
- **注解,不要替换。** 真术语对外行不透明时,保留术语本身,旁边补一句白话解释(卡片的 `em`/`h3` 拆分就是干这个用的)——不要换成团队/作者从没用过的词。
- **不生造大词/伞形词。** 论文没有给一组东西起统一名字,就老实说没有,不要造一个"XX 引擎""YY 框架"式的大词把它包装得比论文本身更宏大。
- **拿不准哪个是标准说法时,问。** 或者把候选摆出来让用户挑。不要把猜的词当成论文原话就直接上 deck。

Brief 里的 VOCABULARY 字段就是白名单。某个词要上页面,但回溯不到论文原文,就删掉或换成能回溯到的。

## 诚实分级(论文语境,不可谈判)

三档标签,永远在页面上可见:

| 标签 | 含义 | 证据门槛 |
|------|------|----------|
| **论文声称 / claimed** | 论文断言但未独立核验 | 正文陈述即可,但要标出"这是声称" |
| **已复现 / reproduced** | 论文自己的实验里被展示 | 有表/图/消融支撑,指得出具体图表号 |
| **存疑 / open** | 有告诫、有效性威胁、或未被证 | 局限节 / 小样本 / 窄设定 |

规则:
- 别把"论文声称"当"已复现"用。声称是论文说的话,复现是论文自己拿数据/图表撑住的话——两者不是一回事。
- 别夸大数字。SOTA、百分点提升、加速比,论文写多少就是多少,不要往上抬。
- 每条主张都要指得出具体的图/表/节。被问"这句是哪来的",答得出来。
- 声称密集的页,加一句诚实脚注(比如"越往右越是声称而非已验证"),尤其在结果页/贡献页上很值。

## 常见失败

- **复述摘要当讲解。** 摘要是论文自己的浓缩推销,不是给听众的解释——deck 要讲清楚"为什么"和"怎么 work",不是把摘要重新排版。
- **过度声称 SOTA / 忽略局限。** 论文自己写了局限节,deck 却假装没看见,是最快失去可信度的方式。
- **编造论文没给的数字。** 没有具体数字就别编一个"听起来合理"的百分比或加速比。
- **用生造大词代替论文自己的术语。** 见上面"说论文自己的语言"一节。
- **把"方法能 work"和"实验证明有效"混为一谈。** 前者是方法论主张(论文声称),后者要有图表撑腰(已复现)——分开讲,别揉在一句话里。
